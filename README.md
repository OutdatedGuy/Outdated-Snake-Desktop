# Outdated-Snake

The Outdated Snake Game on Desktop  
Desktop Version Setup [here](https://github.com/OutdatedGuy/Outdated-Snake-Desktop/releases/latest)

# Start

Run `npm install`  
Run `npm start`  
Run `npm run dist:{mac:arm, mac:x64, win:arm, win:x64}` to develop the Game

# Development

Made using [p5.js](https://p5js.org/) library, [Node.js](https://nodejs.org/) and [electron](https://www.electronjs.org/)  
A desktop based server side snake game which can add your score to database and retrive to show highscore list

[Original Game](https://outdated-snake.outdatedguy.rocks)
